系统技术栈：

前端：vue2，axios, element

后端：spring，maven，mybatis

Java版本：jdk-17

数据库：mysql8



操作指南

1、MySQL中创建一个名叫teaching-manager数据库

2、运行该目录下的那个sql脚本，创建基本的表结构

3、对前后端配置文件信息进行修改，后端修改数据库的连接信息，前端修改文件中的baseURL

前后端常用文件所在路径

后端：.\teaching-manager-hd\src\main\resources\application.properties 	（注：用来设置数据库连接、日志输出等配置信息）

前端：.\teaching-manager-ui\Pc\teaching-manager-pc-ui\src\utils\request.js	  (注：用来设置对后端资源的基本请求路径，请求头等信息）

4、正式运行操作
