# 教务管理系统项目文档

## 1 基本要求
以《数据库原理及安全》课程所学理论知识和实验技能为基础，设计开发了一个教务管理系统。该系统实现了教师、学生、课程、课程成绩等的管理，并采取措施保证敏感信息机密性和数据完整性。

技术栈：
- 前端：Vue2, axios, Element UI
- 后端：Spring Boot, Maven, MyBatis
- Java版本：JDK-17
- 数据库：MySQL 8
- 架构：B/S架构

## 2 需求分析

### 2.1 功能需求
1. **用户管理**：
   - 管理员、教师、学生三种角色
   - 用户登录、密码修改
2. **课程管理**：
   - 课程创建、修改、删除
   - 课程审批流程（待审批/已通过/未通过）
   - 课程状态管理（等待安排/可选/已结课/授课中/待选）
3. **学生管理**：
   - 学生信息维护
   - 学生选课功能
   - 成绩管理
4. **教师管理**：
   - 教师信息维护
   - 课程申请功能
5. **系统管理**：
   - 课程开启/关闭控制
   - 数据库管理

### 2.2 性能需求
1. 支持1000+用户并发访问
2. 响应时间 < 2秒（主要操作）
3. 数据安全：敏感信息加密存储

### 2.3 其他需求
1. 跨平台兼容性（Windows/Linux）
2. 响应式设计（PC/移动端）
3. 数据备份与恢复机制

## 3 系统设计

### 3.1 架构设计
系统采用前后端分离架构：
- 前端：Vue.js单页面应用
- 后端：Spring Boot RESTful API
- 数据库：MySQL 8
- 通信：HTTP/JSON

### 3.2 功能模块划分
1. 用户认证模块
2. 课程管理模块
3. 学生管理模块
4. 教师管理模块
5. 审批流程模块
6. 系统配置模块

### 3.3 数据库设计

#### 3.3.1 数据库表

| 表名 | 列名 | 类型 | 宽度 | 小数位数 | 说明 |
|------|------|------|------|----------|------|
| administrator | administrator_id | int |  |  | 管理员ID |
|  | name | varchar | 15 |  | 姓名 |
|  | account | varchar | 45 |  | 账号 |
|  | password | varchar | 45 |  | 密码 |
| course | course_id | int |  |  | 课程ID |
|  | name | varchar | 30 |  | 课程名称 |
|  | teacher_id | int |  |  | 教师ID |
|  | credit | varchar | 5 |  | 学分 |
|  | hour | varchar | 20 |  | 学时 |
|  | place_id | int |  |  | 地点ID |
|  | description | text |  |  | 课程描述 |
| student | student_id | int |  |  | 学生ID |
|  | student_number | varchar | 45 |  | 学号 |
|  | name | varchar | 15 |  | 姓名 |
|  | student_class | varchar | 45 |  | 班级 |
|  | password | varchar | 45 |  | 密码 |

（完整表结构见`教务管理系统.sql`文件）

#### 3.3.2 表间参照关系
- 课程表(course)关联教师表(teacher)
- 选课表(courses_students)关联课程表和学生表
- 课程审批表(course_application)关联课程和审批状态
- 教师表(teacher)关联学院表(department)

### 3.4 接口设计
RESTful API设计：
- GET /api/courses 获取课程列表
- POST /api/courses 创建新课程
- PUT /api/courses/{id} 更新课程
- DELETE /api/courses/{id} 删除课程
- POST /api/login 用户登录

### 3.5 功能模块设计

#### 3.5.1 用户认证模块
- JWT令牌认证
- 角色权限控制
- 密码加密存储

#### 3.5.2 课程管理模块
- 课程增删改查
- 课程状态管理
- 选课开关控制

#### 3.5.3 审批流程模块
- 课程申请审批
- 审批状态跟踪
- 审批历史记录

## 4 程序编码

### 4.1 后端结构
- controller：处理HTTP请求
- service：业务逻辑实现
- mapper：数据库操作
- dto：数据传输对象
- vo：视图对象

### 4.2 前端结构
- views：页面组件
- components：可复用组件
- api：接口封装
- router：路由管理
- store：状态管理

### 4.3 安全措施
1. 敏感数据加密
2. SQL注入防护
3. XSS攻击防护
4. JWT令牌验证
